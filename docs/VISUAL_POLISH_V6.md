# Nightfall Ops — Visual Polish v6

- Added the supplied battlefield reference as a dark, slowly drifting settings backdrop.
- Location cards now use the individual illustrated location SVGs as full-card backgrounds.
- Mission mode cards and operator cards now use soldier artwork as atmospheric backgrounds with a strong text contrast gradient.
- Enemy takedowns now create a short stylized red impact burst, ground mark, fall pose, and delayed fade rather than vanishing immediately. Effects are deliberately brief and non-photorealistic.
- Cover concealment now requires cover plus blocked line of sight; nearby enemies can still discover a concealed player.
- Economy, payment, authentication, Firestore rules, and Firebase service configuration were not intentionally modified.

Build status: source-level changes only; a complete production build and physical-device gameplay test remain required.
